Build the Les Alpages du Soleil website from scratch, following CLAUDE.md.

1. Read CLAUDE.md fully, then every file listed in its section 1.
2. Create a task list with the phases in CLAUDE.md section 10.
3. Work through the phases in order. At the end of each phase run its gate (see /verify), update `docs/BUILD-REPORT.md` and commit.
4. Do not stop for missing facts: omit the element, note it in the build report, continue.
5. When all phases are done and every check passes, push to `main` and tell the owner what is left for them (from `npm run todo` and `docs/LAUNCH-CHECKLIST.md`).
